# Fonts

## Metropolis (brand font)

Metropolis is the primary typeface per `docs/MetropolisFont.md`. Font files live in **`metropolis/`** (`.otf` from the web project).

- **Loaded in** `app/_layout.tsx`: Regular, Light, Medium, SemiBold, Bold, ExtraBold.
- **Theme** `constants/theme.ts` exposes: `typography.fontFamily.sans`, `.light`, `.medium`, `.semibold`, `.bold`, `.extraBold` for use in styles.
