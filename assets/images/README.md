# Images

## Logo

Place the Desynar logo here when provided:

- **App icon**: Replace `icon.png` with the branded icon (1024×1024 recommended).
- **Splash**: Replace `splash-icon.png` for the splash screen.
- **Adaptive icon (Android)**: Replace `adaptive-icon.png` (foreground layer).
- **Optional**: `logo.png` or `logo.svg` for in-app header/top bar (see `mobile-app/screens/shop-feed.md` — top bar shows logo).

Current files are Expo defaults; update `app.json` if you rename or add assets.
